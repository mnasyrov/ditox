# Contributing to Ditox.js

Thank you for your interest in contributing! Bug reports, feature requests, and
pull requests are welcome.

## Requirements

- Node.js 20 or newer

## Getting started

```shell
git clone https://github.com/mnasyrov/ditox.git
cd ditox
npm ci
npm run build
```

## Project structure

The repository is a monorepo managed by npm workspaces and
[Lerna](https://lerna.js.org):

- `packages/ditox` – the core DI container
- `packages/ditox-react` – dependency injection helpers for React.js

## Checks and tests

- `npm run check` – lint sources with [Biome](https://biomejs.dev) and
  type-check with TypeScript
- `npm test` – run unit tests with Vitest
- `npm run test-coverage` – run tests with a coverage report

Please make sure all checks and tests pass before submitting a pull request.

## Code style

Formatting and linting are handled by Biome. A [husky](https://typicode.github.io/husky)
pre-commit hook checks and formats staged files automatically. To format the
whole project manually:

```shell
npm run format
```

## Commit messages

The project follows the
[Conventional Commits](https://www.conventionalcommits.org) specification.
Release versions and changelogs are generated by Lerna from commit messages, so
please use the conventional format, for example:

```
feat: add eager module binding strategy
fix: handle optional tokens in child containers
docs: update usage examples
```
